# His Voice V2

Expo SDK 58, React Native 0.88, Expo Router, and React Native's New Architecture. V1 remains in the sibling directory as the migration reference.

Use Node 22.13+ (Node 22 LTS recommended) and npm:

```powershell
cd J:\react-native\hisvMobile\his-voiceAPK-V2
npm.cmd ci
npm.cmd start
```

For a local Android development build, run `npm.cmd run android` with the Android SDK and an emulator/device available. Local iOS builds require macOS/Xcode. EAS profiles are provided for development clients, preview APKs, and production store builds. A new native build is required when moving from V1 to V2; this SDK upgrade cannot be delivered as an OTA update.

```text
src/
  app/               File-based routes and root layout
  features/          Sermons, search, bookmarks, audio, settings, welcome, menu, about
  providers/         Typed app state and one-time storage hydration
  shared/            Reusable UI, theme, utilities, storage, route helpers
  data/sermons/      Original offline sermon corpus and audio metadata
assets/              Original images and fonts
```

Routes are small entry points; screen behavior lives in feature folders. New infrastructure uses strict TypeScript. Existing screens remain JSX so the migration preserves behavior without a full UI rewrite; `checkJs` is disabled for these migrated screens.

The app identifiers and EAS project are preserved for in-place upgrades. Existing settings, positions, highlights, last sermon, and bookmarks retain their storage keys. Legacy `bookmarks` data is read only as a fallback to the canonical `sermonBookmarks` key. Startup reads storage before rendering screens, and storage writes are serialized per key. OTA updates use fingerprint runtime matching and the existing update prompt.

Run `npm.cmd run check`, `npm.cmd test`, `npm.cmd run doctor`, and `npm.cmd run export:android` to validate changes. Native projects are generated by Expo and excluded from source control.

The migrated JSX has existing lint warnings (unused code and hook dependency suggestions) that remain visible for follow-up cleanup. `npm audit` currently reports 20 high-severity entries in the SDK-aligned dependency tree, including propagated advisories from Metro's dependencies and code signing libraries. Its suggested forced fixes downgrade Expo/React Native to incompatible older releases; review upstream patches rather than applying `npm audit fix --force`.

Device smoke check: enter from welcome, open text and audio sermons, search and jump to a paragraph, add/remove a bookmark and highlight, change reader settings, restart and verify saved data, then verify Android back navigation. Web audio opens the source page in a browser; Android/iOS retain the embedded WebView.
